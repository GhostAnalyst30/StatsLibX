Simulación Monte Carlo
.monte_carlo(function, n, return_simulations, **kwargs)
function: callable · n: int = 100 · return_simulations: bool = False
→ dict

Realiza n simulaciones de Monte Carlo llamando a function(**kwargs) en cada iteración. Calcula automáticamente media y desviación estándar de los resultados. Con return_simulations=True incluye todos los valores simulados.

ParámetroTipoDefaultDescripción
functioncallable—Función a simular. Debe retornar un valor numérico escalar. Recibirá **kwargs en cada llamada.
nint100Número de simulaciones a ejecutar
return_simulationsboolFalseSi True, incluye la lista completa de simulaciones en el resultado
**kwargsany—Argumentos adicionales que se pasan a function en cada simulación

Retorna:

ClaveTipoDescripción
meanfloatMedia de los n resultados simulados
stdfloatDesviación estándar de los resultados
samplesList[float]Lista completa (solo si return_simulations=True)
Python — Ejemplo 1: Estimación de π
import numpy as np
from statslibx import ComputationalStats

cs = ComputationalStats()

def estimar_pi(n_points=10000):
    """Estima π usando el método de Monte Carlo."""
    x = np.random.uniform(-1, 1, n_points)
    y = np.random.uniform(-1, 1, n_points)
    dentro = np.sum(x**2 + y**2 <= 1)
    return 4 * dentro / n_points

resultado = cs.monte_carlo(estimar_pi, n=500, n_points=5000)
print(f"Estimación de π: {resultado['mean']:.4f}")
print(f"Desviación estándar: {resultado['std']:.4f}")
Python — Ejemplo 2: Valoración de opciones financieras
import numpy as np

cs = ComputationalStats(seed=42)

def option_payoff(S0=100, K=105, T=1, r=0.05, sigma=0.2):
    """Black-Scholes Monte Carlo para una call europea."""
    ST = S0 * np.exp((r - 0.5*sigma**2)*T + sigma*np.sqrt(T)*np.random.normal())
    return max(ST - K, 0) * np.exp(-r*T)

resultado = cs.monte_carlo(option_payoff, n=100000, return_simulations=False)
print(f"Precio estimado de la opción: ${resultado['mean']:.4f}")
print(f"Error estándar: ${resultado['std']:.4f}")
Python — Ejemplo 3: Con simulaciones completas
import numpy as np
import matplotlib.pyplot as plt

def lanzar_dado():
    return np.random.randint(1, 7)

# Retornar todas las simulaciones
resultado = cs.monte_carlo(lanzar_dado, n=10000, return_simulations=True)

print(f"Media: {resultado['mean']:.3f}")  # ~ 3.5
print(f"Std: {resultado['std']:.3f}")

# Graficar distribución de resultados
plt.hist(resultado['samples'], bins=6, edgecolor='black')
plt.title('Distribución de 10,000 lanzamientos')
plt.show()
Nota: La función pasada a monte_carlo() debe retornar un único valor numérico escalar. Los **kwargs se pasan directamente a la función en cada iteración, por lo que son parámetros fijos — no cambian entre simulaciones. Para variar parámetros entre runs, inclúye la aleatoriedad dentro de la función.
