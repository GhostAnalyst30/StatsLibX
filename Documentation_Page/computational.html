🚀 Métodos Computacionales
.bootstrap()
Realiza bootstrapping para estimar intervalos de confianza y distribuciones muestrales.
column: str, statistic="mean", n_bootstrap=1000, confidence=0.95
from statslibx import ComputationalStats
from statslibx.datasets import load_iris

data = load_iris()
comp = ComputationalStats(data)

boot_result = comp.bootstrap(column="sepal_length", statistic="mean", n_bootstrap=5000)
print(f"IC Bootstrap 95%: ({boot_result.lower}, {boot_result.upper})")
.cross_validation()
Realiza validación cruzada k-fold para modelos de regresión/clasificación.
model: str, X_cols: list, y_col: str, k_folds=5, metric="rmse"
cv_scores = comp.cross_validation(
    model="linear_regression",
    X_cols=["sepal_length", "sepal_width"],
    y_col="petal_length",
    k_folds=5
)
print(f"RMSE promedio: {cv_scores.mean():.3f}")
.monte_carlo_simulation()
Simula escenarios usando muestreo Monte Carlo para variables especificadas.
distributions: dict, n_simulations=10000, target_func: callable
# Simulación de rendimiento de inversión
distribuciones = {
    "retorno": {"type": "normal", "mean": 0.08, "std": 0.15},
    "inflacion": {"type": "normal", "mean": 0.02, "std": 0.01}
}

resultados = comp.monte_carlo_simulation(
    distributions=distribuciones,
    n_simulations=10000,
    target_func=lambda x: (1 + x["retorno"]) / (1 + x["inflacion"]) - 1
)
.time_series_analysis()
Análisis de series temporales: descomposición, autocorrelación, pruebas de estacionariedad.
column: str, date_col: str, decomposition="additive"|"multiplicative"
ts_result = comp.time_series_analysis(
    column="ventas",
    date_col="fecha",
    decomposition="additive"
)
print(f"Tendencia: {ts_result.trend}, Estacionalidad: {ts_result.seasonal}")
.optimize_hyperparameters()
Optimiza hiperparámetros de modelos usando grid search o random search.
model_type: str, param_grid: dict, X_cols: list, y_col: str, method="grid"
best_params = comp.optimize_hyperparameters(
    model_type="linear_regression",
    param_grid={"fit_intercept": [True, False]},
    X_cols=["sepal_length", "sepal_width"],
    y_col="petal_length"
)
print(f"Mejores parámetros: {best_params}")
.power_analysis()
Análisis de potencia estadística para determinar tamaño de muestra requerido.
test_type="ttest", effect_size=0.5, alpha=0.05, power=0.8
sample_size = comp.power_analysis(
    test_type="ttest",
    effect_size=0.5,
    alpha=0.05,
    power=0.8
)
print(f"Tamaño de muestra necesario: {sample_size}")
.principal_component_analysis()
Realiza Análisis de Componentes Principales (PCA) para reducción de dimensionalidad.
columns: list, n_components=None (explica varianza), scale=True
pca_result = comp.principal_component_analysis(
    columns=["sepal_length", "sepal_width", "petal_length", "petal_width"],
    n_components=2
)
print(f"Varianza explicada: {pca_result.explained_variance_ratio_}")
.cluster_analysis()
Análisis de clustering (K-means, jerárquico) para segmentación de datos.
columns: list, n_clusters=3, method="kmeans"
clusters = comp.cluster_analysis(
    columns=["sepal_length", "sepal_width", "petal_length", "petal_width"],
    n_clusters=3,
    method="kmeans"
)
print(f"Labels: {clusters.labels_}")
.bayesian_inference()
Inferencia Bayesiana con MCMC para estimación de parámetros.
column: str, prior: dict, n_samples=5000
bayes_result = comp.bayesian_inference(
    column="sepal_length",
    prior={"mean": {"type": "normal", "mu": 5, "sigma": 1}, "sigma": {"type": "uniform", "low": 0, "high": 2}},
    n_samples=5000
)
print(f"Posterior media: {bayes_result.posterior_mean}")
