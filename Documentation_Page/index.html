DescriptiveStats

Media, mediana, moda, varianza, desviación estándar, asimetría, curtosis, percentiles, outliers, correlación, covarianza y regresión lineal.

InferentialStats

Bootstrapping, validación cruzada, simulación Monte Carlo, análisis de series temporales, optimización numérica y métodos computacionales avanzados.

🧪 Ejemplo Rápido

Primeros pasos

from statslibx import DescriptiveStats, InferentialStats
from statslibx.datasets import load_iris

data = load_iris()

# Estadística descriptiva
ds = DescriptiveStats(data)
summary = ds.summary()

# Estadística inferencial
inf = InferentialStats(data)
ci = inf.confidence_interval(column="sepal_length", statistic="mean")
