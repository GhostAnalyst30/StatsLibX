📘 Documentación rápida

Primeros pasos

StatsLibx está diseñada para ser intuitiva. Importa el módulo principal y empieza a analizar datos en pocas líneas:

from statslibx import DescriptiveStats, InferentialStats, UtilsStats
from statslibx.datasets import load_iris

data = load_iris()

ds = DescriptiveStats(data)
inf = InferentialStats(data)
utils = UtilsStats()

stats.summary()
Tip: StatsLibx soporta DataFrames de pandas, listas y arrays de numpy de forma nativa.
🧪 Ejemplos de código reales

Estadística descriptiva avanzada

import statslibx as slx

ds = slx.DescriptiveStats(df)

ds.summary().to_dataframe(
    format="wide"
)

Obtén métricas robustas con manejo automático de valores atípicos.

Regresión lineal con diagnóstico

import statslibx as slx

ds = slx.DescriptiveStats(load_penguins())

ds.linear_regression(
    X = "body_mass_g", 
    y = "flipper_length_mm",
    show_plot = True
    )

Intervalos de Confianza

import statslibx as slx

df = slx.datasets.load_iris()
infer = slx.InferentialStats(df)

# Confidence Interval + Point Estimate
infer.confidence_interval(
    column="bill_length_mm",
    statistic="mean"
)

Interpretación: si p < 0.05, existen diferencias significativas entre grupos.
