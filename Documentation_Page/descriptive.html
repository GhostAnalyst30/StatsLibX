DescriptiveStats Module

Análisis estadístico descriptivo completo para DataFrames, listas y arrays NumPy

📊 Métodos Disponibles
.summary()
Genera un resumen estadístico completo incluyendo media, mediana, moda, varianza, desviación estándar, asimetría, curtosis, percentiles, mínimo y máximo.
Parámetros: format="wide" | "long"
from statslibx import DescriptiveStats
import pandas as pd

df = pd.read_csv("datos.csv")
ds = DescriptiveStats(df)
resumen = ds.summary().to_dataframe(format="wide")
print(resumen)
.central_tendency()
Calcula media, mediana y moda para todas las columnas numéricas.
ct = ds.central_tendency()
print(ct)  # {'col1': {'mean': 10.5, 'median': 10.0, 'mode': 8}}
.dispersion()
Calcula varianza, desviación estándar, rango, rango intercuartil (IQR) y coeficiente de variación.
dispersion = ds.dispersion()
print(dispersion)
.shape()
Calcula asimetría (skewness) y curtosis (kurtosis) para evaluar la forma de la distribución.
forma = ds.shape()
# Retorna {'skewness': 0.45, 'kurtosis': 2.1}
.percentiles()
Calcula percentiles personalizados (25, 50, 75 por defecto).
pct = ds.percentiles(percentiles=[10, 25, 50, 75, 90])
print(pct)
.outliers()
Detecta valores atípicos usando método IQR o Z-score.
method="iqr" | "zscore", threshold=1.5
outliers_info = ds.outliers(method="iqr", threshold=1.5)
print(outliers_info)  # {'col1': [índices de outliers]}
.correlation()
Calcula matriz de correlación (Pearson, Spearman o Kendall).
method="pearson" | "spearman" | "kendall"
corr_matrix = ds.correlation(method="pearson")
print(corr_matrix)
.covariance()
Calcula matriz de covarianza entre variables numéricas.
cov_matrix = ds.covariance()
print(cov_matrix)
.linear_regression()
Ajusta un modelo de regresión lineal simple con visualización opcional.
X: str (columna independiente), y: str (columna dependiente), show_plot: bool
resultado = ds.linear_regression(X="body_mass_g", y="flipper_length_mm", show_plot=True)
print(f"Coef: {resultado.coef}, R²: {resultado.r2}")
.frequency_table()
Genera tabla de frecuencias para variables categóricas.
freq = ds.frequency_table(column="species")
print(freq)  # Frecuencia absoluta y relativa
