InferentialStats Module

Pruebas de hipótesis, intervalos de confianza y análisis inferencial

📈 Métodos de Inferencia Estadística
.confidence_interval()
Calcula intervalo de confianza para una media, proporción o varianza con nivel de confianza personalizable.
column: str, statistic="mean"|"proportion"|"variance", confidence=0.95
from statslibx import InferentialStats
from statslibx.datasets import load_iris

data = load_iris()
inf = InferentialStats(data)

ci = inf.confidence_interval(column="sepal_length", statistic="mean", confidence=0.95)
print(f"IC 95%: ({ci.lower}, {ci.upper})")
.ttest_one_sample()
Prueba t de una muestra para comparar la media con un valor poblacional.
column: str, popmean: float, alternative="two-sided"
result = inf.ttest_one_sample(column="sepal_length", popmean=5.5)
print(f"t-statistic: {result.statistic}, p-value: {result.pvalue}")
.ttest_two_sample()
Prueba t para dos muestras independientes (puede ser con varianzas iguales o diferentes).
group_col: str, value_col: str, equal_var=True
result = inf.ttest_two_sample(group_col="species", value_col="sepal_length", group1="setosa", group2="versicolor")
print(f"p-value: {result.pvalue}")
.ttest_paired()
Prueba t para muestras pareadas (antes/después).
result = inf.ttest_paired(before="pretest", after="posttest")
print(result)
.anova_oneway()
ANOVA de un factor para comparar medias entre múltiples grupos.
group_col: str, value_col: str
anova_result = inf.anova_oneway(group_col="species", value_col="petal_length")
print(f"F: {anova_result.F}, p: {anova_result.pvalue}")
.chi_square_test()
Prueba de independencia chi-cuadrado para variables categóricas.
col1: str, col2: str
chi2 = inf.chi_square_test(col1="species", col2="class")
print(f"Chi2: {chi2.statistic}, p: {chi2.pvalue}")
.normality_test()
Prueba de normalidad (Shapiro-Wilk o Kolmogorov-Smirnov).
column: str, method="shapiro"|"ks"
norm = inf.normality_test(column="sepal_length", method="shapiro")
print(f"Es normal? p={norm.pvalue}")
.mann_whitney_u()
Prueba no paramétrica U de Mann-Whitney para dos muestras independientes.
mw = inf.mann_whitney_u(group_col="species", value_col="sepal_length", group1="setosa", group2="versicolor")
print(mw)
.kruskal_wallis()
Prueba no paramétrica de Kruskal-Wallis para múltiples grupos.
kw = inf.kruskal_wallis(group_col="species", value_col="petal_width")
print(f"H: {kw.statistic}, p: {kw.pvalue}")
.levene_test()
Prueba de homogeneidad de varianzas (Levene).
lev = inf.levene_test(group_col="species", value_col="sepal_length")
print(lev)
